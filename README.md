# Дашборд задач для GitHub Pages + Google Sheets

Цей комплект робить сайт-дашборд, який працює так:

- Google Таблиця = база даних.
- GitHub Pages = красивий дашборд для телефону і компʼютера.
- Google Apps Script = міст між сайтом і таблицею.
- Якщо додати/змінити задачу в таблиці — натискаєш **Оновити дані** на сайті, і вона зʼявляється в дашборді.
- Якщо додати/змінити задачу на сайті — вона записується назад у Google Таблицю.

## 1. Файли

```text
index.html          — сторінка дашборду
style.css           — дизайн і мобільна адаптація
app.js              — логіка сайту і запити до Apps Script
gas/Code.gs         — код для Google Apps Script
README.md           — ця інструкція
```

## 2. Налаштування Google Apps Script

1. Відкрий свою Google Таблицю.
2. Натисни **Розширення / Extensions → Apps Script**.
3. Видали весь старий код у файлі `Code.gs`.
4. Встав код з файлу `gas/Code.gs`.
5. У `Code.gs` знайди:

```js
API_TOKEN: 'CHANGE_ME_SECRET_TOKEN'
```

6. Заміни `CHANGE_ME_SECRET_TOKEN` на свій секретний код, наприклад:

```js
API_TOKEN: 'task-dashboard-2026-secret'
```

Важливо: такий самий код треба буде вставити в `app.js`.

## 3. Опублікувати Apps Script як Web App

1. У Apps Script натисни **Deploy → New deployment**.
2. Тип вибери **Web app**.
3. Поле **Execute as**: вибери **Me**.
4. Поле **Who has access**: вибери **Anyone**.
5. Натисни **Deploy**.
6. Дай дозволи Google, якщо попросить.
7. Скопіюй **Web app URL**.

## 4. Підключити Web App URL до сайту

Відкрий `app.js` і знайди:

```js
API_URL: 'PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE',
API_TOKEN: 'CHANGE_ME_SECRET_TOKEN',
```

Заміни на свої дані:

```js
API_URL: 'https://script.google.com/macros/s/ТВІЙ_DEPLOYMENT_ID/exec',
API_TOKEN: 'task-dashboard-2026-secret',
```

`API_TOKEN` у `app.js` і `Code.gs` має бути однаковий.

## 5. Залити сайт на GitHub

1. Створи новий репозиторій на GitHub, наприклад `task-dashboard`.
2. Завантаж туди файли:
   - `index.html`
   - `style.css`
   - `app.js`
   - папку `gas` можна теж залишити в репозиторії як інструкцію, але сайт її не використовує.
3. В репозиторії відкрий **Settings → Pages**.
4. У **Build and deployment** вибери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Натисни **Save**.
6. Через короткий час GitHub дасть посилання типу:

```text
https://твій-нік.github.io/task-dashboard/
```

## 6. Як користуватися

### Додати задачу через сайт

1. Натисни **+ Додати задачу**.
2. Заповни назву, пріоритет, виконавця, дедлайн, опис.
3. Натисни **Створити задачу**.
4. Задача автоматично додасться в аркуш `Задачі`.

### Змінити статус

1. На картці задачі вибери новий статус.
2. Сайт одразу відправить зміну в Google Таблицю.

### Додати коментар

1. На картці задачі натисни **Коментар**.
2. Впиши апдейт або блокер.
3. Запис піде в аркуш `Коментарі_Лог`.

### Оновити дані з таблиці

Якщо щось змінили вручну в Google Таблиці, натисни на сайті **Оновити дані**.

## 7. Важливо про безпеку

Це простий варіант для внутрішнього контролю задач. `API_TOKEN` видно в коді сайту, тому він не є повноцінним захистом від технічно підкованих людей. Для командного внутрішнього використання цього достатньо, але для публічного сервісу потрібна нормальна авторизація.

## 8. Якщо не працює

Перевір по черзі:

1. Чи вставлений правильний Apps Script Web App URL у `app.js`.
2. Чи однаковий `API_TOKEN` у `app.js` і `gas/Code.gs`.
3. Чи Apps Script опублікований як **Web app**.
4. Чи доступ у deployment стоїть **Anyone**.
5. Чи назви аркушів не змінені:
   - `Задачі`
   - `Підзадачі`
   - `Коментарі_Лог`
   - `Люди_Ролі`
   - `Довідники`
